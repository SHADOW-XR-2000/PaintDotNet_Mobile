# TilePaint (рабочее название)

Растровый редактор для Android по мотивам Paint.NET: слои, история действий, кисть и ластик.
Главная цель — большие изображения без большого расхода памяти.

## Как это устроено

Всё хранится **тайлами** 256×256 пикселей. Модуль `core` — чистый Kotlin без Android, поэтому его
тесты запускаются прямо в GitHub Actions.

| Класс | Что делает |
|---|---|
| `Tile` | 256×256 пикселей в нативной (off-heap) памяти, формат ARGB без premultiply, как `android.graphics.Color` |
| `TileStore` | Все тайлы документа. Держит в RAM только последние использованные (LRU), остальные сбрасывает на диск. Счётчики ссылок и copy-on-write |
| `TileLayer` | Разреженный слой: пустые и полностью прозрачные тайлы не существуют и памяти не занимают |
| `History` | Undo/redo. Хранит только изменённые тайлы (до изменения), а не копии слоёв |
| `Document` | Слои + общее хранилище + история. `edit("имя") { ... }` — одно действие для отмены |
| `Brush` | Круглая кисть со сглаживанием и ластик |

Правила, которые стоит помнить:

- Однопоточное ядро. Тайл, который вернули `read()`/`write()`, действителен только до следующего вызова хранилища.
- Менять пиксели нужно через `TileLayer` (`setPixel`, `forEachWritableTile`), чтобы работали copy-on-write и история.
- Добавление и удаление слоёв пока не попадает в историю.

В `app` — минимальный интерфейс: холст (один палец рисует, два — зум и перемещение), отмена/повтор,
кисть/ластик, палитра, размер кисти и строка со счётчиками тайлов, чтобы видеть расход памяти.

## Сборка на GitHub (без ПК)

1. Залейте проект в репозиторий, ветка `main`.
2. Вкладка **Actions** → **Android build** запускается сама на каждый push (или вручную через *Run workflow*).
   Сначала прогоняются тесты ядра, потом собирается APK.
3. APK лежит в релизе **Latest debug build** (раздел *Releases*) — откройте ссылку на телефоне и установите.
   Также он есть в артефактах запуска (`TilePaint-debug`).

Debug-сборка подписывается автоматически, поэтому ставится без дополнительных шагов
(Android попросит разрешить установку из браузера).

## Дальше по плану

1. Кэш превью-пирамиды (сейчас при отдалении тайлы просто прореживаются, тонкие линии могут пропадать).
2. Рендер через OpenGL ES вместо копирования тайлов в Bitmap.
3. Выделение (прямоугольник, лассо, волшебная палочка), заливка, пипетка.
4. Панель слоёв: режимы наложения, прозрачность, порядок.
5. Эффекты и коррекции — по тайлам, с предпросмотром на уменьшенной копии.
6. Открытие/сохранение PNG/JPEG и собственный формат со слоями.
